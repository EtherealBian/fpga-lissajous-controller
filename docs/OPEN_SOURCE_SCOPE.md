# 开源范围

## 已包含

- 19 个可综合 SystemVerilog RTL 模块及详细中文注释
- 7 个功能测试平台与 3 个仿真替代模型
- UART 主机参考工具和两类频偏 Python 仿真
- Jetson Nano 视觉测频与闭环主程序，含四个内嵌算法/协议子系统和详细中文注释
- Vivado/eLinx 构建脚本、实验 PSF 文件、算法与协议文档
- 2026 年江苏赛区 F 题原文 PDF

## 未包含

- 个人简历、保研材料、姓名联系方式等个人文件
- Vivado `.Xil` 缓存、日志、波形、综合网表、布局布线结果和 bitstream
- 厂商用户手册 PDF；请从板卡或器件厂商官方渠道获取
- 最终 XDC/PSF 引脚约束、AD/DA 模拟前端原理图和成品硬件接线表
- 原始目录中缺失的 `lissajous_phase_local.py` 相位提取模块，以及与个人设备绑定的摄像头标定 JSON、现场图像和调试视频
- 参赛设计报告、现场照片及未获授权的第三方资料
