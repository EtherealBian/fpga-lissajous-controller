# 系统架构

## 总体信号链

```text
有线模式
信号源 ──> AD1 ──> 去中值/限幅 ──> 全采样 I/Q DPLL ──> 相位模式/幅值 ──> DAC1 ──> 示波器 Y
   └────────────────────────────────────────────────────────────────────────> 示波器 X

无线模式
摄像头 ──> Jetson Nano视觉程序 ──UART──> FPGA 任意频率/相位 DDS ──> DAC1 ──> 示波器 Y
信号源 ─────────────────────────────────────────────────────────────────────> 示波器 X
```

有线主链不复制 ADC 瞬时样本，而是估计输入相位和频率后重新合成正弦，因此输出幅值稳定。无线模式先使用已冻结的 100 kHz 校准字修正 FPGA 晶振 ppm 误差，再执行 Jetson 下发的频率与相位。Jetson 端先经四档选档和八帧鲁棒融合得到 100 Hz 量化频率，再用双侧精扫判图及绝对相位搜索闭环调整图形。

## 图形生成

| 模式 | Y 轴信号 | 理想图形 |
|---|---|---|
| 直线 | 与 X 同频、同相 | 对角线 |
| 正交 | 与 X 同频、相差 90° | 圆；通道刻度不等时为椭圆 |
| 二倍频 | X 频率的 2 倍 | 水平“∞”形 |

幅值档位由 `lissajous_core.sv` 在 LUT 输出后统一缩放，对应示波器 Y 轴 2、4、6、8 div 峰峰值目标。

## 时钟域

- 50 MHz：板载输入参考时钟，仅进入 Clocking Wizard。
- 100 MHz：按键、UART 和无线控制状态机。
- 30 MHz：ADC/DAC、DPLL、标定器与 DDS。

慢变化电平经双触发器同步；单周期操作事件采用翻转位跨域。源域先稳定多位配置，再翻转事件位，目的域双同步后用异或恢复脉冲。复位采用异步置位、各时钟域同步释放。

## 数值格式

- ADC/DAC：10 位 offset-binary，中值码 512，±5 V 满量程。
- 目标 ±2 V 峰值：数字峰值码 205。
- DDS：48 位相位累加器，高 32 位送正弦 LUT。
- 相角：32 位整周格式，`0x40000000` 为 90°。
- UART 频率：mHz 无符号整数；相位：Q0.16 周。

## 工程边界

仓库没有最终 XDC/PSF 引脚约束、现场摄像头标定 JSON 或成品硬件接线表。Jetson 主程序已收录，但其外部相位提取模块 `lissajous_phase_local.py` 未在原始归档中找到，因此完整相位补偿仍需补回该文件。`lissajous_top.psf` 是实验性 eLinx 工程文件，不能替代针对实际板卡复核后的正式约束。
