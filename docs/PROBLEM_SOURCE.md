## 要求与实现映射

| 赛题要求 | 仓库实现 |
|---|---|
| 1. 直通模式显示 8×8 div 对角线 | 顶层安全路由与 `lissajous_core.sv` 直线模式 |
| 2. 同频、正交、同幅，显示直径 8 div 的圆 | `continuous_iq_dpll.sv` +90° 相位模式与满幅缩放 |
| 3. 二倍频、同幅，显示水平“∞” | 锁定相位左移一位的二倍频模式 |
| 4. Y 轴峰峰值 2/4/6/8 div | `scale_for_amplitude` 四档定点缩放 |
| 5. 三个独立按键自动模式、摄像头闭环、≤10 s 控制、≥5 s 稳定 | FPGA 提供三键启动、UART 状态机、标定 DDS 和声光状态接口；摄像头识别策略仅有 `phase_sim/` 信号模型，成品视觉程序未开源 |
| 6. 设计报告 | 仓库提供架构、算法索引、协议和验证文档；不包含参赛原报告 |

本仓库是工程代码归档，不应把“仿真模型存在”理解为赛题第 5 项视觉系统已经可直接复现。
