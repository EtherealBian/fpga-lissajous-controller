# RTL 中文注释规范

所有可综合 RTL 的作者统一为 Ethereal，文本编码统一为 UTF-8（无 BOM），换行符统一为 LF。

## 模块级说明

每个模块开头说明模块名称、功能、核心算法、数值格式、时钟/复位或握手规则。注释描述设计意图和约束，不简单重复语句字面含义。

## 过程内说明

- 在状态机、跨时钟域、定点舍入、限幅、流水线边界和握手处说明“为什么这样做”。
- 数值常量必须说明单位，例如 Hz、mHz、采样数、整周相位或 DAC 码。
- 对低有效信号使用 `_n` 后缀，对单周期事件使用 `_pulse`，对跨域中间级使用 `_meta`、`_sync`。
- 非阻塞赋值用于时序逻辑，组合块给出完整默认值，避免锁存器。
- 仿真专用模型必须明确标注“不可加入综合源”。

仓库不在每条注释前附加作者标签，避免干扰正常代码阅读；作者信息仅保留在模块级说明中。
