## 题目来源

仓库收录的 [`2026-NUEDC-Jiangsu-F-Lissajous.pdf`](problem/2026-NUEDC-Jiangsu-F-Lissajous.pdf) 是江苏赛区版三页题目原文，标题为“2026 年全国大学生电子设计竞赛江苏赛区赛（TI 杯）暨模拟电子系统设计专题赛选拔赛赛题——李萨如图形显示控制装置（F 题）”。

- 文件大小：327704 字节
- SHA-256：`CAA7AA9A4293735AF81A48B4FC0E0318850539AD87651834EBC2F336AEBB14E5`
- 全国大学生电子设计竞赛培训网题目汇总：https://res.nuedc-training.com.cn/topic/2026/topic_from_31.html
- 福州大学赛题发布页及全国赛区赛附件：https://fjuedc.fzu.edu.cn/info/1013/1243.htm

已将江苏赛区版本与公开发布的全国赛区赛 F 题交叉核对：题名、1 kHz～100 kHz/100 Hz 步进、六项要求及 120 分评分结构一致；公开附件在页眉和排版上略有差异。

题目 PDF 的著作权仍归原发布单位所有，仓库仅为竞赛学习和方案复现保留原文，不适用本仓库 MIT 代码许可证。

## 要求与实现映射

| 赛题要求 | 仓库实现 |
|---|---|
| 1. 直通模式显示 8×8 div 对角线 | 顶层安全路由与 `lissajous_core.sv` 直线模式 |
| 2. 同频、正交、同幅，显示直径 8 div 的圆 | `continuous_iq_dpll.sv` +90° 相位模式与满幅缩放 |
| 3. 二倍频、同幅，显示水平“∞” | 锁定相位左移一位的二倍频模式 |
| 4. Y 轴峰峰值 2/4/6/8 div | `scale_for_amplitude` 四档定点缩放 |
| 5. 三个独立按键自动模式、摄像头闭环、≤10 s 控制、≥5 s 稳定 | FPGA 提供三键启动、UART 状态机、标定 DDS 和声光状态接口；`vision/jetson_freq.py` 实现 Jetson 四档选档、八帧测频、双侧精扫和相位闭环调度。原始归档缺少其外部相位提取模块，故完整相位补偿尚不能独立复现 |
| 6. 设计报告 | 仓库提供架构、算法索引、协议和验证文档；不包含参赛原报告 |

本仓库是工程代码归档。视觉主程序已公开，但仍需现场九点标定数据、实际摄像头/示波器环境以及缺失的 `lissajous_phase_local.py`，不应把“主程序存在”理解为第 5 项硬件系统已经可以开箱复现。
